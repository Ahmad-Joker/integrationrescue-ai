# Demo recording checklist

**Before** (also complete [LIVE_DEMO_CHECKLIST.md](LIVE_DEMO_CHECKLIST.md))
- [ ] Screen recorder set to 1920×1080, 30 fps, system audio off, microphone on (OBS Studio is free; Windows Game Bar works)
- [ ] External or headset microphone; quiet room; test 10 s of audio and listen back
- [ ] Browser: one tab, bookmarks bar hidden, zoom 110%, extensions that show icons hidden
- [ ] Nothing private visible: no `.env`, terminal with codes, email, or other tabs. The access code is never on screen
- [ ] State reset; featured incident selected; Decision maker = Live AI agent (Gemini)
- [ ] Gemini quota available for at least two attempts

**Recording**
- [ ] Record the full raw run once without narration (proof of a live run; keep the file)
- [ ] Record narration separately or live; follow DEMO_SCRIPT_2_MIN.md; do not read faster to fit, cut instead
- [ ] Show the LIVE AI AGENT banner before saying "AI"
- [ ] Approve on camera

**Editing**
- [ ] Final length 1:50–2:00, hard maximum 2:00
- [ ] Every speed-up or cut captioned ("sped up 4×", "waiting cut")
- [ ] Captions or subtitles in English (auto-generate, then correct)
- [ ] Lower-third with the recording date; end card with the repository URL
- [ ] No claim on screen that is not in TECHNICAL_EVIDENCE.md

**Publish**
- [ ] Upload as **Unlisted** (YouTube) or as the portal requires; title "IntegrationRescue: 2-minute live agent demo"
- [ ] Test the link in a private window; add it to the deck (slide 7) and SUBMISSION_READINESS.md
