# Decision log

- **2026-10-31 — Local processes + SQLite, no Docker.** Docker Desktop is broken on the dev machine and not needed;
  per-environment SQLite files make sandbox cloning a file copy.
- **2026-10-31 — Single orchestrator state machine, no LangGraph.** Persistence, approval pause and resume are simple
  with an explicit phase field + checkpoints; avoids a dependency and keeps every transition inspectable.
- **2026-10-31 — Handler code returns actions; trusted service applies them.** Lets customer code run in a child process
  while all side effects are validated by deterministic code.
- **2026-10-31 — Regression tests generated by deterministic code** from the captured event and ledger, and must fail
  on unpatched code. The agent cannot author the test that judges its own patch.
- **2026-10-31 — Deterministic provider is a rule-based baseline**, not recorded LLM replay. Used for CI and as the
  evaluation baseline; labelled "DETERMINISTIC" everywhere. It deliberately does not attempt code repairs.
- **2026-10-31 — Manual Messages-API loop** (not the beta tool runner) so the orchestrator controls phases, budgets and
  persistence; default `claude-opus-5-5`, effort `medium`, server-side fallbacks enabled.
- **2026-10-31 — UI can only launch the deterministic eval** to prevent accidental model spend.
- **2026-10-31 — Vite + React without a component library**; hash routing; CSS tokens with dark mode.
